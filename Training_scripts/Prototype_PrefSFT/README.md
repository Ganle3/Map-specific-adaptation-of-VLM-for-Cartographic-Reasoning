# Prototype PrefSFT

First run `precompute_vision_embeddings.py --cache-dir <DIR>` once, then pass the same directory as `--vision-cache-dir` to both `precompute_baseline_scores.py` and `train_prototype_prefsft.py`. This persists final frozen-ViT Z per question and on cache hits skips all ViT blocks; the learned routing then performs P->Z collection and Z->P_img distribution before the merger. The cache must be regenerated after changing the adapter or image preprocessing. `question-batch-size` is the number of questions per optimizer step; `trajectory-micro-batch-size` controls the size of each teacher-forcing forward, while all scores of a question remain connected until its preference loss is backpropagated.

The model backbone (including the checkpoint-3000 LoRA adapter) is frozen. The routing module has trainable P and fixed buffered alpha; checkpoints include both, optimizer/scheduler state, args, step and epoch. `visualize/visualize_prototypes.py` saves P-to-patch collection maps, patch-to-P distribution maps, prototype cosine and attention-overlap matrices, and residual magnitude.
