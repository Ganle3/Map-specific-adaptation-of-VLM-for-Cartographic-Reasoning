Definition. Values are actual post-softmax decoder attention weights restricted to merged image-token keys and averaged over query heads. “All layers” always takes the patch-wise maximum over the raw 36 decoder-layer maps first. The recommended p99 contrast then clips only the display scale after that maximum, preventing one extreme patch from making every other patch nearly black. “Literal maximum” reproduces strict max normalization. “Maximum over all inference steps” additionally takes a raw patch-wise temporal maximum before display scaling. Raw float32 weights remain unchanged in each variant's attention.npz.

Relay timing. At layer 0, x_t has not yet received this step's relay output. At layer l>0, its query state already contains relay interactions from preceding layers. Within a layer, x_t and r_t attention are computed jointly; that layer's updated hidden state becomes the next layer's query.
