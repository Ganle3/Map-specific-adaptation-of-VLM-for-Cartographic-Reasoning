Relay token R1: query → image keys

Relay token R2: query → image keys

Meaning. Each map is the actual post-softmax decoder attention from one relay query to merged image-token keys, averaged across attention heads. The viewer preserves R1 and R2 separately. The heat-map contrast is normalized independently at the 99th percentile, so use image attention mass and raw max for absolute comparisons.

Timing. Relay1 is computed once during prefill. It changes across decoder layers while the prompt is processed, then each layer's resulting relay K/V is cached. There is therefore no inference-step slider. R2 is causally after R1 and may also use R1, so the two maps need not represent independent extractors.
